Установка Keywarden

Две части: приложение на компьютере хранит базу, расширение браузера заполняет из неё логины. Бесплатно, без аккаунта.

Linux и macOS, одна команда

$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Сверяет загрузку с SHA256SUMS и ставит в ~/.local/bin без root. Прочитать скрипт

1 · Приложение

Выберите систему. Приложение работает в фоне и запускается вместе с сеансом.

# x86_64
$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Linux

Ставит программы, службу systemd, ярлык в меню и связь с Firefox. Wayland и X11.

Вручную из архива
$ tar xzf keywarden-*-linux-x86_64.tar.gz
$ cd keywarden-*-linux-x86_64
$ ./install.sh
# keywarden-*-windows-x86_64.zip из Releases
# распакуйте в постоянную папку и там:
> .\keywarden-ui.exe
> .\kw.exe browser-setup

Windowsбета

Установщика пока нет: zip с четырьмя программами. SmartScreen один раз спросит, потому что файлы пока не подписаны: «Подробнее», затем «Выполнить в любом случае».

Файлы релиза 
# Apple Silicon
$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

macOSбета

Apple Silicon. Кладёт программы в ~/.local/bin и подключает браузер. Файлы из curl не попадают в карантин.

Вручную из архива
$ tar xzf keywarden-*-macos-arm64.tar.gz
$ cd keywarden-*-macos-arm64
$ xattr -dr com.apple.quarantine .
$ ./kw browser-setup
$ ./keywarden-ui

2 · Расширение браузера

Заполняет логины и коды 2FA, сохраняет новые пароли и ключи доступа. Общается только с приложением на этом же компьютере.

Firefox

Доступно

Подписано Mozilla, обновляется само.

Добавить в Firefox

Chrome

Скоро

Скоро в Chrome Web Store. Пока что zip из релиза ставится вручную как распакованное расширение.

Edge

Скоро

Edge Add-ons после Chrome. Zip для Chrome уже сейчас ставится в Edge вручную.

Brave

Скоро

Brave, Vivaldi, Opera: версия для Chrome, из Chrome Web Store.

Вручную: распакуйте keywarden-extension-*-chrome.zip, откройте chrome://extensions, включите режим разработчика, «Загрузить распакованное», затем kw browser-setup --chrome-id <id>.

На телефоне

Приложения Keywarden для Android и iOS в работе. База это обычный файл KeePass, поэтому уже сегодня его открывает любое приложение KeePass из папки синхронизации.

Менеджеры пакетов

Установка и обновления привычными инструментами. Сейчас подключаются.

Arch Linux, AUR

Скоро

paru -S keywarden-bin

macOS, Homebrew

Скоро

brew install onokashino/tap/keywarden

Windows, winget

Скоро

winget install onokashino.Keywarden

Проверка загрузки

В каждом релизе есть SHA256SUMS. Скрипт сверяет его сам, вручную это одна строка.

$ sha256sum -c SHA256SUMS --ignore-missing

Из исходников

Rust 1.92 или новее. Зависимости для сборки в документации.

$ git clone https://github.com/onokashino/keywarden
$ cd keywarden
$ cargo build --release -p keywarden-daemon -p keywarden-cli -p keywarden-host -p keywarden-ui
