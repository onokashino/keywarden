Установка Keywarden

Приложение на компьютере хранит базу и делает всю работу. Расширение браузера, а позже и приложения для телефона подключаются к тому же файлу KeePass. Всё бесплатно.

Быстрее всего, Linux и macOS:

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Скачивает последний релиз, сверяет с SHA256SUMS и ставит в ~/.local/bin без root. Скрипт можно сначала прочитать.

Приложение для компьютера

Скрипт установки

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Ставит программы, службу systemd для демона, ярлык в меню и связь с Firefox. Нужная версия: ... | KEYWARDEN_VERSION=v0.1.0 sh.

Из архива

Скачайте keywarden-*-linux-x86_64.tar.gz из последнего релиза, затем:

tar xzf keywarden-*-linux-x86_64.tar.gz
cd keywarden-*-linux-x86_64
./install.sh

По желанию: wtype (автоввод на Wayland) или xdotool (X11).

Из архива

Скачайте keywarden-*-windows-x86_64.zip из последнего релиза, распакуйте в постоянную папку, например %LOCALAPPDATA%\Programs\Keywarden, и запустите keywarden-ui.exe. Затем из этой папки подключите браузер:

.\kw.exe browser-setup

Программы пока не подписаны, поэтому SmartScreen один раз спросит: «Подробнее», затем «Выполнить в любом случае».

Скрипт установки

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Apple Silicon. Кладёт программы в ~/.local/bin и подключает браузер. Файлы, скачанные через curl, не попадают в карантин, лишних шагов нет.

Из архива

tar xzf keywarden-*-macos-arm64.tar.gz
cd keywarden-*-macos-arm64
xattr -dr com.apple.quarantine .
./kw browser-setup
./keywarden-ui

Сборка пока не нотаризована, отсюда шаг с xattr.

Расширение браузера

Заполняет логины и коды 2FA, сохраняет новые пароли и ключи доступа. Общается только с приложением Keywarden на этом же компьютере, поэтому сначала поставьте приложение.

  • FirefoxдоступноУстановить →
  • Chromeпока что: zip из релизаскоро
  • Edgeскоро
  • Braveпока что: zip из релизаскоро

Для Chrome, Edge или Brave уже сейчас: распакуйте keywarden-extension-*-chrome.zip из релиза, откройте chrome://extensions, включите режим разработчика, нажмите «Загрузить распакованное», затем выполните kw browser-setup --chrome-id <id> с id, который там показан.

Проверка загрузки

В каждом релизе есть файл SHA256SUMS. Скрипт установки сверяет его сам, вручную так:

# Linux
sha256sum -c SHA256SUMS --ignore-missing
# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing
