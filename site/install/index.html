Install Keywarden

Two parts: the app on your computer keeps the vault, the browser extension fills logins from it. Free, no account.

Linux and macOS, one command

$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Checks the download against SHA256SUMS and installs into ~/.local/bin without root. Read the script

1 · The app

Pick your system. The app runs in the background and starts with the session.

# x86_64
$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Linux

Installs the binaries, a systemd user service, a menu entry and the Firefox connection. Wayland and X11.

By hand from the archive
$ tar xzf keywarden-*-linux-x86_64.tar.gz
$ cd keywarden-*-linux-x86_64
$ ./install.sh
# keywarden-*-windows-x86_64.zip from Releases
# unpack it to a folder you keep, then there:
> .\keywarden-ui.exe
> .\kw.exe browser-setup

Windowsbeta

No installer yet: a zip with four programs. SmartScreen asks once because the files are not signed yet: "More info", then "Run anyway".

Release files 
# Apple Silicon
$ curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

macOSbeta

Apple Silicon. Puts the programs in ~/.local/bin and connects the browser. Files from curl are not quarantined.

By hand from the archive
$ tar xzf keywarden-*-macos-arm64.tar.gz
$ cd keywarden-*-macos-arm64
$ xattr -dr com.apple.quarantine .
$ ./kw browser-setup
$ ./keywarden-ui

Check the download

Every release has SHA256SUMS. The script checks it for you, by hand it is one line.

$ sha256sum -c SHA256SUMS --ignore-missing

From source

Rust 1.92 or newer. Build dependencies are in the docs.

$ git clone https://github.com/onokashino/keywarden
$ cd keywarden
$ cargo build --release -p keywarden-daemon -p keywarden-cli -p keywarden-host -p keywarden-ui
