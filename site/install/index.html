Install Keywarden

The desktop app keeps your vault and does the work. The browser extension and, later, the phone apps connect to the same KeePass file. Everything is free.

Quickest way, Linux and macOS:

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Downloads the latest release, checks it against SHA256SUMS and installs into ~/.local/bin without root. Read the script first if you like.

Desktop app

Install script

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Installs the binaries, a systemd user service for the daemon, a menu entry and the Firefox host. A specific version: ... | KEYWARDEN_VERSION=v0.1.0 sh.

From the archive

Download keywarden-*-linux-x86_64.tar.gz from the latest release, then:

tar xzf keywarden-*-linux-x86_64.tar.gz
cd keywarden-*-linux-x86_64
./install.sh

Optional: wtype (autotype on Wayland) or xdotool (X11).

From the archive

Download keywarden-*-windows-x86_64.zip from the latest release, unpack it to a folder you keep, for example %LOCALAPPDATA%\Programs\Keywarden, and run keywarden-ui.exe. Then register the browser host from that folder:

.\kw.exe browser-setup

The binaries are not signed yet, so SmartScreen asks once: "More info", then "Run anyway".

Install script

curl -fsSL https://onokashino.github.io/keywarden/install.sh | sh

Apple Silicon. Puts the binaries in ~/.local/bin and registers the browser host. Files downloaded by curl are not quarantined, so no extra step.

From the archive

tar xzf keywarden-*-macos-arm64.tar.gz
cd keywarden-*-macos-arm64
xattr -dr com.apple.quarantine .
./kw browser-setup
./keywarden-ui

The build is not notarized yet, hence the xattr step.

Browser extension

Fills logins and 2FA codes, saves new passwords and passkeys. It talks only to the Keywarden app on the same computer, so install the app first.

  • FirefoxavailableInstall →
  • Chromeuntil then: zip from the releasesoon
  • Edgesoon
  • Braveuntil then: zip from the releasesoon

For Chrome, Edge or Brave right now: unpack keywarden-extension-*-chrome.zip from the release, open chrome://extensions, turn on Developer mode, press "Load unpacked", then run kw browser-setup --chrome-id <id> with the id shown there.

Check the download

Every release has a SHA256SUMS file. The install script checks it for you; by hand:

# Linux
sha256sum -c SHA256SUMS --ignore-missing
# macOS
shasum -a 256 -c SHA256SUMS --ignore-missing

From source

Rust 1.92 or newer. Details and Linux build dependencies are in the docs.

git clone https://github.com/onokashino/keywarden
cd keywarden
cargo build --release -p keywarden-daemon -p keywarden-cli -p keywarden-host -p keywarden-ui
