Sync through your folder

The vault is one encrypted file. Any folder sync carries it between devices, and Keywarden merges the changes entry by entry. No server of ours, no account.

1 · Pick a way

Keywarden recognises these folders and their conflict copies by itself.

Syncthing

Recognised

Device to device, no cloud in between. The best fit.

Nextcloud

Recognised

Your own server or a hosted one.

Dropbox

Recognised

Works out of the box.

Other folders

Works

Google Drive, OneDrive, iCloud, a network share. Conflict copies are not recognised.

WebDAV

Soon

Keywarden talks to your server itself: Nextcloud, Synology, any WebDAV. No sync app needed.

Directly between computers

Soon

Two computers with Keywarden exchange the vault with each other, no folder or cloud.

2 · Set it up

Three steps, once per device.

  1. 1

    Move the vault

    Settings, Sync, "Move to folder". Keywarden writes the vault there, checks it and keeps the old file in backups.

  2. 2

    Sync the folder

    Add the same folder to Syncthing, Nextcloud or Dropbox on the other computer and on the phone.

  3. 3

    Open the same file

    Keywarden on another computer, KeePassDX on Android, KeePassium or Strongbox on iOS. Same master password.

How changes merge

Keywarden watches the file. When it changes on disk, the new version is merged into the open vault.

Entry by entry

The newer edit wins. The other version is not lost, it goes into the entry history.

Deletions count

An entry deleted on one device is deleted everywhere, unless someone edited it after that.

Conflict copies

Copies made by Syncthing, Nextcloud and Dropbox are merged and moved to backups.

Mass deletion waits

If a change removes more than 5 entries or 10% of the vault, Keywarden asks first: accept or keep them.

Undo

Before every merge a snapshot is saved. The log in Settings undoes a merge, and the undo reaches other devices too.

Old copy warning

If a sync brings back an older version of the file, you get a warning.

Good to know

  • Use the same master password (and key file) on every device: a copy under another password is not merged, only reported.
  • Keep the key file and YubiKey settings out of the synced folder.
  • Keywarden saves KDBX 4.1. KeePassXC 2.7+, KeePassDX and KeePassium read it.
  • Sync makes no network requests from Keywarden: only your sync tool moves the file.
